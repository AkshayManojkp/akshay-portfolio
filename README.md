# Akshay Manoj KP — Portfolio

Faithful static recreation of the supplied animated portfolio, updated with project descriptions and profile links from the portfolio profile README.

## Stack

- HTML for semantic page structure
- CSS for the original visual system, responsive layout, and animations
- Vanilla JavaScript for interaction and motion
- Three.js r128 for the existing 3D effects (loaded from cdnjs)

This static site requires no build step or framework. Serve this directory locally with any static file server, or deploy it to Vercel with `vercel --prod`.

Project and social links point to the public GitHub repositories and profiles listed in the source profile README. No email address was present in that source, so the contact links use verified public profiles instead.
